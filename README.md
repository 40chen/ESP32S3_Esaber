# ESP32S3_Esaber

基于 ESP32-S3 的光剑项目：68 颗 WS2812 灯带（2026-10-03 换装：来回折成 4 等份×17，物理序→数据链 remap 见 `src/drivers/PixelStrip.cpp`）、MPU6050 姿态传感、I2S 音效（SD 卡双目录音源）、240×240 TFT 屏幕、Web 控制台与 Blender 动捕联动。

> 2026-09-26 修订：设备只工作在 AP 模式，不连接家庭路由器；原"辅助 WiFi 登录"流程作废。

> 2026-10-03（no-display 分支现状）：① 屏幕相关功能（GC9A01 圆屏/眼睛/二维码/背光）已注释停用（0c9c098）；② 音效文件名白名单放行 UTF-8 中文 + Web 音效下拉两级分组（4152cbb）；③ 灯带 31→68 四等份蛇形折 + 灯序 remap 入仓（规格图《ESaber 灯序 remap 规格图》05 节 方案 A：kRemap[物理序]=数据链，i0=P0 进线端第一颗=刀柄侧；效果逻辑零改动，扫向基准"自柄向尖"）。

## 项目需求

1. **光剑功能**：
   根据陀螺仪的数据变化形成不同的灯效和音效（开刃/收刃、挥动、碰撞）

2. **屏幕功能**：
   - 显示 Web 控制台二维码；按 BOOT 键调出二维码，再次按 BOOT 键返回眼睛画面
   - 二维码上方提示"请先连接热点 Esaber-Setup"，二维码下方显示热点名（免密直连）
   - 非二维码画面显示一只会随陀螺仪数据变化左看右看的眼睛

3. **Web 功能**：
   设备以 AP 模式运行，热点 Esaber-Setup（免密直连）。手机连接该热点后访问 http://192.168.4.1 直接进入控制台（无需任何登录或 WiFi 配置步骤），可自定义光剑颜色、亮度、特效、音量、眼睛图案和三路音效（开机音/关机音/底噪），Web 界面的 UI 设计参照苹果的设计

4. **Blender 动捕**：
   姿态四元数 + 航位推算位置通过 UDP 发送到电脑（动捕协议 v1：31 字节定长二进制帧、50Hz、端口 5005；默认目标 192.168.4.2 = 热点首个客户端，控制台「动捕地址」可改），让虚拟世界的模型和现实世界的光剑联动。唯一接收端脚本：`shared/esaber-blender-link/blender_receiver.py`（契约见同目录 `PROTOCOL.md`）；旧 CSV 接收端已废弃归档（`shared/blender/deprecated/`）

## 当前实现（2026-09-26 固件优化后）

- **灯效**（7 种，Web 可切）：常亮、呼吸、彩虹（挥动加速）、扫描、不稳定（等离子抖动+浪涌）、火焰、星尘
- **开刃/收刃**：两端向中间点亮 / 收回，收刃带渐隐拖尾；碰撞闪光跟随刀色、时长随撞击强度
- **三路音效**（Web 可配，SD 卡双目录音源 `sfx_default`/`sfx_user`，wav/flac/mp3）：开机音=开刃触发、关机音=收刃触发、底噪=亮刀期间无缝循环（任意时长自适应）；切换即存 NVS，断电不丢。固件启动自动创建两目录；旧固件的根目录音源与裸文件名设置自动兼容（回落顺序 sfx_default → 根目录 → sfx_user）
- **屏幕眼睛**：用户素材纹理渲染；碰撞时眯眼联动；正常/睡觉/生气三种图案
- **Web 控制台**：单页直达（热点模式下无任何前置表单），颜色/亮度(0-100%)/特效/音量/眼睛图案/三路音效，设置持久化到 NVS
- **系统**：ArduinoOTA 无线升级（主机名 esaber，密码 esaber123）；上电自检页；掉电原因日志；回路栈水位诊断

> 屏幕二维码提示文案以 ASCII 字体渲染为 "JOIN HOTSPOT"（内置 GLCD 字库不含中文），中文点阵视觉稿由设计侧提供后可替换为位图渲染。

## 3.3V 供电优化（2026-09-28）

AMS1117-3.3 无大铜箔时实际连续输出按 500-600mA 计（压差 1.7V 热受限）。固件侧四项削减，均为独立改动，可单独回滚：

| 改动 | 位置 | 效果 | 回滚方式 |
|---|---|---|---|
| 背光 LEDC PWM 66%（10kHz / 10-bit） | `HardwareConfig.h` 三常量 + `DisplayDriver.cpp` | 稳态 -10~25mA，3.3V 轨最大单项常载 | `enableBacklight()` 换回 `digitalWrite(HIGH)` |
| CPU 240→160MHz | `platformio.ini` 单行 `board_build.f_cpu` | 常态 -15~40mA，同降 LDO 结温 | 删该行重烧 |
| softAP beacon 100→300ms | `WifiService.cpp` 单行 | 射频周期发包率降至 1/3 | 删该行 |
| 开刃串行化：灯条渐亮延至功放 settle（20ms）之后 | `SaberController.cpp` | PA 浪涌与 LED 电流不再同 tick 叠加 | 删 `ignitionLightDue_` 门控 |

真机验收点：QR 屏扫码仍顺畅（唯一视觉验证点）；眼睛帧率与音频无可感卡顿（若卡顿先回滚 f_cpu 一行）；上电串口 reset reason 不应出现 BROWNOUT。
若 clash 瞬间仍掉电：灯条挂 5V 轨，属 5V 跌落经输入级联到 3.3V——对策在硬件侧（灯条就近并 470-1000µF bulk 电容 / 加粗供电线径），软件四项即为终态。
