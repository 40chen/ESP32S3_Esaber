# ESP32S3_Esaber

基于 ESP32-S3 的光剑项目：56 颗 WS2812 灯条、MPU6050 姿态传感、I2S 音效（SD 卡音源）、240×240 TFT 屏幕、Web 控制台与 Blender 动捕联动。

> 2026-09-26 修订：设备只工作在 AP 模式，不连接家庭路由器；原"辅助 WiFi 登录"流程作废。

## 项目需求

1. **光剑功能**：
   根据陀螺仪的数据变化形成不同的灯效和音效（开刃/收刃、挥动、碰撞）

2. **屏幕功能**：
   - 显示 Web 控制台二维码；按 BOOT 键调出二维码，再次按 BOOT 键返回眼睛画面
   - 二维码上方提示"请先连接热点 Esaber-Setup"，二维码下方显示热点名（免密直连）
   - 非二维码画面显示一只会随陀螺仪数据变化左看右看的眼睛

3. **Web 功能**：
   设备以 AP 模式运行，热点 Esaber-Setup（免密直连）。手机连接该热点后访问 http://192.168.4.1 直接进入控制台（无需任何登录或 WiFi 配置步骤），可自定义光剑颜色、亮度、特效、音量和眼睛图案，Web 界面的 UI 设计参照苹果的设计

4. **Blender 动捕**：
   将陀螺仪数据通过 UDP 发送到电脑（默认 10 Hz，端口 5005），让虚拟世界的模型和现实世界的光剑联动

## 当前实现（2026-09-26 固件优化后）

- **灯效**（7 种，Web 可切）：常亮、呼吸、彩虹（挥动加速）、扫描、不稳定（等离子抖动+浪涌）、火焰、星尘
- **开刃/收刃**：两端向中间点亮 / 收回，收刃带渐隐拖尾；碰撞闪光跟随刀色、时长随撞击强度
- **屏幕眼睛**：虹膜颜色跟随刀色；碰撞时眯眼联动；正常/睡觉/生气三种图案
- **Web 控制台**：单页直达（热点模式下无任何前置表单），颜色/亮度(0-100%)/特效/音量/眼睛图案，设置持久化到 NVS
- **系统**：ArduinoOTA 无线升级（主机名 esaber，密码 esaber123）；上电自检页；掉电原因日志；回路栈水位诊断

> 屏幕二维码提示文案以 ASCII 字体渲染为 "JOIN HOTSPOT"（内置 GLCD 字库不含中文），中文点阵视觉稿由设计侧提供后可替换为位图渲染。
